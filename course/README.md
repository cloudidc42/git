# หลักสูตร Git / GitHub / GitLab ฉบับสมบูรณ์

หลักสูตรสอนเขียนและพัฒนาโปรแกรม/เว็บแอปพลิเคชันด้วย **Git, GitHub และ GitLab**
ตั้งแต่ระดับพื้นฐานที่สุด จนถึงระดับมืออาชีพและระดับโลก

- แบ่งเป็น **100 Part**
- ครอบคลุม **1000 ขั้นตอน (Step)** เรียงลำดับต่อเนื่องกัน
- แต่ละ Part มีเนื้อหาที่ใช้งานได้จริง 100% ความยาว 500–3000+ บรรทัด
- เขียนเป็นภาษาไทย อธิบายละเอียด มีตัวอย่างคำสั่งจริงที่รันได้ทันที

## โครงสร้างหลักสูตร

ดูสารบัญฉบับเต็มได้ที่ [`00-สารบัญ-หลักสูตร.md`](./00-สารบัญ-หลักสูตร.md)

เนื้อหาทั้งหมดแบ่งเป็น 10 เฟส (Phase):

| เฟส | ชื่อเฟส | Part | Step |
|---|---|---|---|
| 1 | ปูพื้นฐานความคิดเรื่อง Version Control และ Git | 01–05 | 1–50 |
| 2 | การทำงานกับไฟล์และ Branch เบื้องต้น | 06–15 | 51–150 |
| 3 | GitHub เบื้องต้น | 16–30 | 151–300 |
| 4 | การทำงานเป็นทีมด้วย Git/GitHub | 31–45 | 301–450 |
| 5 | GitLab | 46–55 | 451–550 |
| 6 | Git ขั้นสูง / Internals | 56–65 | 551–650 |
| 7 | CI/CD | 66–75 | 651–750 |
| 8 | DevOps / Security / Compliance | 76–85 | 751–850 |
| 9 | มืออาชีพ / Enterprise Practice | 86–95 | 851–950 |
| 10 | ระดับโลก / Leadership | 96–100 | 951–1000 |

```
...

```
